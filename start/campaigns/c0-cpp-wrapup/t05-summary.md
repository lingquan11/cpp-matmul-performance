# T05 总结（≤ 1000 字）

- **线**：必做 | **计划用时**：2h | **前置**：T03、T04（或已按砍线规则缩小）
- **一句话目标**：用不超过 1000 字，向一个懂 C++ 但没看过这个仓库的人讲清楚"我从这个项目学到了什么"

## 步骤
1. 【me】先**不看资料**，花 20 分钟手写提纲，拍照存为 `journey/notes/summary-outline.jpg`（同时作为闭卷解释）。
2. 【me】写 `results/summary.md`，四节，每个论断都指向 `results/experiments/` 中的具体目录：
   1. **循环顺序**：快了多少，原因是什么（01）
   2. **分块**：为什么小规模失败、什么规模开始生效、是否符合预测（02、04）
   3. **SIMD**：编译器做了什么、手写做了什么、离理论值还差多少（03、05）
   4. **边界与未完成**：只看耗时能证明什么、不能证明什么；哪些部分是 AI 写的；哪些没做完
3. 【ai】只做错别字和链接检查，**不改写论述**。
