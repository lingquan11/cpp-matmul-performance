# plan/ 学习计划（任务卡）

本文件夹存放 Day 9 起的学习计划任务卡，按段收录。任务卡由学习计划打磨流程定稿后写入，写好一块收一块，不等整段凑齐。

用途：供后续读取本仓库的 tutor 型 AI 按卡教学——读取当前要执行的任务卡，依据卡内的分步拆解、验收标准与停下条件引导学习者执行、答疑与验收。学习者本人也可直接按卡执行。

## 文件

- [seg1-scale-sweep.md](seg1-scale-sweep.md)：段一「规模扫描实测」任务卡。已收 S1-T1～S1-T11（共 17 块，余下定稿后补入）。
- 段二～段五：各段任务卡定稿后在本文件夹新增对应文件，并在本索引补行。

## 读取约定（给 tutor 型 AI）

1. 当前进度以仓库根目录 PROJECT_STATE.md 为唯一真相，先读它确认下一个未执行的任务块，再读本文件夹对应任务卡。
2. 只按卡教学与验收：不擅自改任务编号、日期与用时；卡内标〔推断〕的值不是事实，实测读不到时按卡写「未读到」，不代填、不编造数据。
3. 历史实验数据与旧记录不倒填、不覆盖；换计时口径即新实验。
