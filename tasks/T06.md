# T06 v1.0 收口

- **线**：必做 | **计划用时**：1h | **前置**：T05
- **一句话目标**：别人 clone 下来，30 秒能看到结论，5 分钟能复现正确性测试

## 步骤
1. 【me】README 顶部放一张总表：循环顺序 / 分块 / SIMD 三类优化，在小规模（≤256）和大规模（≥1024）下各自带来的 GOPS 和加速比，每个数字链接到对应的 CSV。
2. 【ai】README 中的复现命令改成一段可以直接复制的命令（Windows x64 Native Tools），以及 CI 中的 Linux 命令；确认两者实际都能跑通。
3. 【me】把 CAMPAIGN.md 中所有必做项的状态更新为最终结果。
4. 【me】打 tag 并发布 Release：`git tag -a v1.0 -m "..."`，Release 说明直接引用 SUMMARY 的摘要。
5. 【me】用 reviewer.md 做战役复盘，把输出追加到 log。

## 所有权
- `[me]`：总表中的数字、tag 和 Release、复盘
- `[ai]`：复现命令的整理与验证

## 机器验收（开工前写死，AI 不得修改）
- [ ] GitHub 上存在 `v1.0` Release
- [ ] 打 tag 的那次提交上 CI 显示绿色
- [ ] README 总表中的每个数字都能链接到 CSV
- [ ] log 中有战役复盘的输出
