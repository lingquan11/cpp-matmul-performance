# T04 SIMD：自动向量化 vs AVX2 手写

- **线**：必做 | **计划用时**：4h | **前置**：T03（复用其 kernel 和框架）
- **一句话目标**：搞清楚编译器到底有没有对 ikj 做向量化、用的是多宽的向量，以及手写 AVX2 能多快

## 材料（一手来源）
- MSVC 自动向量化与向量化报告：https://learn.microsoft.com/cpp/parallel/auto-parallelization-and-auto-vectorization 、`/Qvec-report`：https://learn.microsoft.com/cpp/build/reference/qvec-report-auto-vectorizer-reporting-level
- MSVC `/arch:AVX2`：https://learn.microsoft.com/cpp/build/reference/arch-x64
- 原因代码对照表（C5001/C5002 的 reason code）：https://learn.microsoft.com/cpp/error-messages/tool-errors/vectorizer-and-parallelizer-messages
- Intel Intrinsics Guide（查 `_mm256_loadu_si256`、`_mm256_mullo_epi32`、`_mm256_add_epi32`、`_mm256_set1_epi32`）：https://www.intel.com/content/www/us/en/docs/intrinsics-guide/index.html

## 步骤
1. 【me】对 T03 的 ikj 内层循环，用 `/O2 /Qvec-report:2` 编译（可以用现有的 `scripts/vec-report.bat`），记录 C5001 或 C5002 以及原因代码。
2. 【me】再用 `/O2 /arch:AVX2 /Qvec-report:2` 编译。用 `/FAs` 生成汇编，在 ikj 内层循环中查找 `xmm` 和 `ymm` 寄存器（可以用 `scripts/scan-asm-keywords.py` 辅助），确定实际使用的向量宽度。
3. 【me】手写 `matmul_ikj_avx2`：内层 j 循环每次处理 8 个 int，尾部用标量处理。
4. 【me】正确性：与 T03 的 ikj 逐元素比较，包括 n 不是 8 的倍数的情况（例如 n = 1001）。
5. 【me】测量：n ∈ {512, 1024, 2048} × {ikj `/O2`, ikj `/O2 /arch:AVX2`, ikj_avx2 手写}，测量条件与 T03 相同。
6. 【me】报告：三种结果的 GOPS 对比，以及向量化报告和汇编证据的摘录。
