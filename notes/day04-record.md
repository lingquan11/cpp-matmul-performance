## 我完成的内容

### 目标①：程序规模扩展

我将矩阵容量设置为 `MAX_N = 256`，通过运行时输入 `n` 决定本次计算规模，并使用两重循环自动初始化输入矩阵：

- `A[i][j] = i + j + 1`
- `B[i][j] = 2 * i + j + 1`

我测试了 `n = 1、2、3、4`，结果符合预期；对 `n = 0` 和 `n = 257`，程序能拒绝非法输入。

我能解释两种边界问题的区别：`n = 0` 时循环条件一开始不成立，循环体不执行；`n = 257` 超过数组容量，若没有检查就可能造成越界访问和未定义行为。

### 目标②：计时入门

我使用 `std::chrono::steady_clock` 记录开始和结束时间，并将时间间隔转换为毫秒。

当前计时口径是：
- A、B 输入矩阵初始化：不计时。
- C 的清零与矩阵乘法：计时。
- 输出和正确性检查：不计时。

实际运行截图记录：
