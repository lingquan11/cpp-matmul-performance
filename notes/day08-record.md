## 需要保留的技术边界
- Top-down Memory Bound 不是简单的“CPU 完全停顿时间比例”。
- Core Bound 增加不证明一定是 ROB 或执行端口。
- 平均带宽利用率 55% 不足以绝对排除局部带宽或延迟瓶颈。
- MLP 变化不自动证明因果。
- instructions、cycles、IPC、时间必须对应同一目标和区间。
- `task-clock` 多线程解释需结合线程数。
- 所有教学示例数据不得写入正式结果 CSV。
