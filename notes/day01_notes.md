- 审查结论：代码逻辑正确，程序输出为 11。

## 原始输入

A = [[2, 1], [3, 4]]
B = [[5, 2], [1, 6]]

## 计算过程

矩阵乘法中，C[0][0] 是 A 的第 0 行与 B 的第 0 列对应元素的乘积之和：

C[0][0] = A[0][0] × B[0][0] + A[0][1] × B[1][0]
        = 2 × 5 + 1 × 1
        = 11

- c00 初始化为 0，作为累加起点。
- k 从 0 遍历到 1，覆盖两项乘积，数组下标均在有效范围内。
- A[0][k] 选取 A 的第 0 行；B[k][0] 选取 B 的第 0 列。
- += 将两项乘积累加，由 cout 打印 11，并换行。
