# Day 1：我先算了一个元素

2026-10-22，北京时间。我花了 30 分钟，记在每日任务记录里。这一天我只算两个 2×2 矩阵乘积里的 C[0][0]。程序输出是 11，和我手算的一样。

A = [[2, 1], [3, 4]]
B = [[5, 2], [1, 6]]

C[0][0] 是 A 的第 0 行和 B 的第 0 列乘完再加起来：

C[0][0] = A[0][0] × B[0][0] + A[0][1] × B[1][0]
        = 2 × 5 + 1 × 1
        = 11

我把 c00 先写成 0，不然第一次 += 没有起点。k 从 0 走到 1，两项乘积都盖住了，下标也没越界。A[0][k] 一直是 A 的第 0 行，B[k][0] 一直是 B 的第 0 列。用 += 是因为要累加，不能用一次赋值把前一项盖掉。cout 打出 11 然后换行。

程序在 `src/day01_matrix.cpp`，结果放在变量 c00 里。完整的 2×2 我留到 Day 2，写在 `src/day02_matrix.cpp`。下一步我打算加上行和列的循环，把四个元素都算出来再打印。这份笔记就停在 Day 1。
