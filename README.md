# cpp-matmul-performance

从三重循环出发的 C++ 矩阵乘法性能实验项目 —— 我的 AI 芯片入门项目。

## 项目目标

矩阵乘法是 AI 芯片（NPU / AI 加速器）最核心的计算负载。这个项目从最朴素的三重循环实现开始，一步步走完「正确性 → 性能测量 → 缓存与分块优化 → 理解硬件数据流」的全过程，目标是把课本上的矩阵乘法，变成可测量、可优化、可复现的工程实验，并为后续学习脉动阵列与 NPU 架构打基础。

## 路线图

- [ ] **阶段 A · 算法实现**：完整三重循环实现矩阵乘法，用小矩阵手算结果和参考实现验证正确性，分析时间复杂度
- [ ] **阶段 B · 性能测量**：计时方法、控制变量（矩阵规模、循环顺序、编译优化选项），观察缓存与数据局部性对性能的影响
- [ ] **阶段 C · 分块优化与实验报告**：分块（tiling）优化，产出一份可复现的实验报告（环境、方法、数据、结论齐全）
- [ ] **阶段 D · 脉动阵列与 SCALE-Sim**：理解脉动阵列数据流，用 SCALE-Sim 对照前面的实测结果

## 目录结构

```
src/         矩阵乘法的实现代码
tests/       正确性测试（手算对照、参考实现比对）
benchmarks/  性能测量代码与脚本
results/     实验结果数据与图表
reports/     阶段实验报告
notes/       学习笔记与知识整理
```

每个目录里都有一份 README，写明该目录放什么、按什么约定放。

## 使用方式

- 语言：C++17
- 实现文件放入 `src/` 后，示例编译命令（以第一个实现文件为例）：

```bash
g++ -O2 -std=c++17 -o matmul src/matmul_naive.cpp
```

- 每次实验的结果数据存入 `results/`，结论写进 `reports/`，保证任何一次实验都能按记录复现。
